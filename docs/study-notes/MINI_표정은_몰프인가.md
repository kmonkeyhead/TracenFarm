# MINI 표정은 몰프인가

## 결론

스페셜 위크 MINI 얼굴 표정은 일반적인 `몰프(Morph)` 또는 Unity의 `BlendShape` 방식이 아니다. 눈, 입, 눈썹 메시가 사용하는 텍스처 아틀라스의 UV 위치를 변경하는 방식이다.

## 용어 구분

### 몰프 또는 BlendShape

메시 정점의 위치를 저장해 두고 가중치에 따라 모양을 변형한다. 입꼬리, 눈꺼풀, 볼 형태처럼 실제 얼굴 메시의 형태가 바뀐다.

### UV 표정 또는 표정 아틀라스

하나의 큰 텍스처에 여러 눈·입·눈썹 그림을 배치하고, UV 오프셋을 변경해 표시할 칸을 선택한다. MINI 모델은 이 방식이다.

### 본 애니메이션

귀나 머리처럼 Transform 회전과 위치가 변하는 부분이다. 얼굴 텍스처 전환과 별개의 시스템이다.

## MINI 표정 인덱스 범위

- 눈: 좌우 각각 `0..14`
- 입: `0..18`
- 눈썹: 좌우 각각 `0..8`
- 볼: 별도 오버레이 메시 표시 여부와 텍스처 종류

따라서 이 프로젝트에서는 `페이셜 몰프 컨트롤러`보다 `UV 표정 컨트롤러`라는 이름이 기술적으로 더 정확하다.
