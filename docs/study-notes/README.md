# 우마무스메 MINI 학습 노트

이 폴더에는 프로젝트 진행 중 사용자가 질문한 내용과 `왜 동작하지 않는가`에 대한 분석을 Markdown 문서로 저장한다.

질문은 별도 요청이 없어도 `categories`의 유형별 문서에 자동으로 누적한다. 깊은 분석이 필요한 질문은 별도 상세 문서로 작성한 뒤 유형별 문서에서 연결한다.

## 작성 원칙

- 단순 작업 결과가 아니라 원인과 구조를 설명한다.
- 관찰한 증상, 확인 방법, 원인, 해결 방법을 구분한다.
- 추측과 실제 검증 결과를 구분한다.
- Unity와 우마무스메 내부 용어가 다르면 둘 다 기록한다.
- 같은 질문은 중복 기록하지 않고 기존 설명을 보완한다.
