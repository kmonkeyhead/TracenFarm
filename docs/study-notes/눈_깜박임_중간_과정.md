# 눈 깜박임에 중간 과정이 없었던 이유

## 증상

눈이 즉시 완전히 닫혔다가 즉시 원래 눈으로 돌아와 기계적으로 보였다.

## 원인

초기 경량 컨트롤러가 다음 두 상태만 전환했다.

```text
현재 눈 → 완전히 감은 눈 → 현재 눈
```

UV 표정은 BlendShape처럼 두 형태 사이를 자동 보간하지 않는다. 서로 다른 아틀라스 칸을 선택하는 불연속적인 이미지 전환이기 때문이다.

## 자연스러운 처리 방법

아틀라스에 있는 반쯤 감은 눈 이미지를 중간 단계로 사용한다.

```text
현재 눈
→ 반쯤 감은 눈
→ 완전히 감은 눈
→ 반쯤 감은 눈
→ 현재 눈
```

현재 확인한 대표 인덱스는 다음과 같다.

- 기본 눈: `0`
- 반쯤 감은 눈 후보: `3`
- 완전히 감은 눈: `8`
- 웃으며 감은 눈: `9`

각 단계는 짧은 시간 간격으로 전환해야 한다. 웃는 프리셋처럼 이미 감은 눈을 사용 중이라면 자동 깜박임을 생략하는 편이 자연스럽다.
