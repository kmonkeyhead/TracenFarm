# 카메라와 시네머신 질문

카메라 추적, 화면 구도, Cinemachine 설정 등 게임 카메라에 관한 질문을 모은다.

## 캐릭터 추적 방식 선택

- **캐릭터가 움직일 때 카메라도 따라가게 하려는데, 카메라 Transform을 직접 움직이기보다 Cinemachine을 사용하는 것이 좋은가?**  
  좋다. 현재 목표는 카메라 보간 수식을 직접 만드는 것이 아니라 캐릭터를 안정적으로 추적하고 게임에 맞는 구도를 조정하는 것이다. Cinemachine은 실제 `Main Camera`와 추적 규칙을 분리하고, Follow 대상·위치 오프셋·Damping·카메라 전환을 Inspector에서 조정할 수 있어 이번 학습 단계와 포트폴리오 양쪽에 적합하다. 현재 프로젝트는 Unity `6000.5.7f1`이며 Cinemachine이 아직 설치되지 않았으므로 Package Manager에서 Unity 6 호환 Cinemachine 3 계열을 설치한다. 구버전 강좌의 `Cinemachine Virtual Camera`는 Cinemachine 3에서 주로 `Cinemachine Camera`라는 이름으로 표시되는 점에 주의한다.

  첫 구현은 회전 입력이나 충돌 회피 없이 고정된 탑다운/쿼터뷰 추적으로 제한한다. 캐릭터 루트와 별개로 가슴 또는 몸 중심 높이에 빈 `CameraTarget`을 두고 이를 Tracking Target으로 지정하면 모델 피벗과 애니메이션 흔들림의 영향을 줄일 수 있다. 처음에는 Position Control의 Follow 계열 동작으로 위치 오프셋과 Damping만 조절하고, 카메라 회전은 고정한다. 플레이 중 이동·정지·방향 전환에서 구도, 지연감, 미세 떨림을 확인한 뒤 Dead Zone이나 충돌 회피 같은 기능을 단계적으로 추가한다.
