# 얼굴 텍스처가 보이지 않았던 이유

## 증상

- 몸과 머리카락은 정상적으로 보였다.
- 얼굴 바탕은 흰색에 가까웠다.
- 눈, 입, 눈썹이 전혀 표시되지 않았다.
- 꼬리도 흰색으로 표시됐다.

## 확인 결과

눈, 입, 눈썹, 볼, 얼굴 바탕과 꼬리 머티리얼의 `_MainTex` 참조가 비어 있었다. PNG 파일은 정상적으로 추출되어 있었지만 AssetRipper가 서로 다른 번들에 있는 텍스처와 머티리얼의 참조를 자동 복원하지 못했다.

## 원인

모델 프리팹, 공용 얼굴 머티리얼, 캐릭터별 표정 텍스처가 서로 다른 AssetBundle에 저장되어 있다. 번들을 개별적으로 변환하면서 일부 외부 참조가 끊어졌다.

즉 표정 데이터가 없었던 것이 아니라 다음 연결이 누락된 상태였다.

```text
눈 머티리얼   → 스페셜 위크 눈 아틀라스
입 머티리얼   → 스페셜 위크 입 아틀라스
눈썹 머티리얼 → 스페셜 위크 눈썹 아틀라스
얼굴 머티리얼 → 공용 피부 텍스처
볼 머티리얼   → 공용 볼 텍스처
꼬리 머티리얼 → 스페셜 위크 꼬리 텍스처
```

## 볼에 흰 사각형이 나타난 이유

볼 텍스처에는 알파 채널이 없다. 흰색 배경을 중립값으로 사용하고 분홍색 부분만 얼굴 색에 곱하는 `Multiply` 합성 방식이다.

일반 알파 블렌딩을 사용하면 흰 배경까지 출력되어 얼굴에 흰 사각형이 나타난다. URP 셰이더를 다음 곱셈 블렌딩으로 변경해 해결했다.

```shaderlab
Blend DstColor Zero
```

## 교훈

텍스처 파일이 존재한다는 사실과 머티리얼에 텍스처가 연결되어 있다는 사실은 다르다. 추출 후에는 반드시 머티리얼의 `_MainTex` 참조를 확인해야 한다.
